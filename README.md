## 📌 Project Status
* **Current Version:** v1 stable
* **Base System:** Debian Core
* **Desktop Environment:** XFCE
* **Target Stable Release:** v1.2 + (Future v2.0 will be based on Debian 14/15)

## 🖥️ Minimum System Requirements
Koppie Linux follows the minimum requirements for Debian 13 / 14. Minimum and recommended specs:

- Architecture: 64-bit (x86_64)
- Minimum RAM: 2 GB (4 GB recommended for smoother performance)
- Disk space: 20 GB free (40 GB recommended)
- Display: 1024×768 minimum resolution
- Internet: Required during installation to fetch packages (see warning above)
