# ☕ Koppie Linux

A modern XFCE-based distribution refined for multitasking and stability, crafted by a young Indonesian developer. Experience Linux as it should be—freshly brewed for everyone.

## 📌 Project Status
* **Current Version:** v1.0 LTS (Development / Testing Build)
* **Base System:** Debian Core
* **Desktop Environment:** XFCE
* **Target Stable Release:** v1.9 (Future v2.0 will be based on Debian 14)

## 🌐 Official Website & Download
You can download the early ISO and check the SHA-256 Checksum on our official website:
👉 **[koppielinux.netlify.app](https://netlify.app)**

## 🛠️ What to Expect in Next Release (v1.1)
* Custom XFCE visual enhancements (modern icons & themes)
* Pre-installed App Store for easy software installation
* Deep debloating (removing unused default packages)
